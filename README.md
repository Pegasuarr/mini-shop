MINI MERQE is a mini shop built for assignment purposes only. It features a vanilla HTML/CSS/JS frontend and a Go backend connected to PostgreSQL, with 24 curated children's clothing and accessory products across 5 categories — Tops, Bottoms, Outerwear, Footwear, and Accessories. Users can browse products, filter by category, add items to cart, and place orders which are saved directly to the database. Product images are stored as file paths in PostgreSQL and served locally from the images/ folder. The stack is intentionally lightweight: no frameworks, no ORMs — just clean Go with pgx and standard database/sql. 


⚠️Note: this project has no authentication or security implementation as it is for academic/assignment use only.
